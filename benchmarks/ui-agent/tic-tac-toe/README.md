# Tic Tac Toe Benchmark

This benchmark asks an agentic coding model to build a polished single-file tic tac toe demo.

## Goal

Produce a single `index.html` file that runs without a build step and includes a distinctive finish animation when the game ends.

## Constraints

- Work from the provided prompt and repository context only
- Keep the output self-contained in one HTML file
- Prefer portable browser APIs
- Do not require additional local setup to preview the result
